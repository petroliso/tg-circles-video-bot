# 🎬 Telegram Бот для Обработки Видео

Этот проект представляет собой Telegram-бота для обработки видео с возможностью конвертации в кружки и наложения эффектов. Бот также собирает статистику использования.

![Telegram Бот для Обработки Видео](https://img.shields.io/badge/Telegram-Bot-blue)
![Node.js](https://img.shields.io/badge/Node.js-14+-green)
![Telegraf](https://img.shields.io/badge/Telegraf-4.15.0-orange)

## 📋 Функциональность

Бот предлагает пользователям следующие возможности:

- **Обработка видео**: конвертация видео в кружки
- **Наложение эффектов**: добавление различных эффектов к видео (рамка, блюр, реверс, цветокоррекция)
- **Просмотр статистики**: информация о количестве обработанных видео и примененных эффектов

## 🔧 Требования

Для запуска проекта вам понадобится:

- Node.js (версия 14.0.0 или выше)
- npm (менеджер пакетов Node.js)
- Токен Telegram-бота (получите у [@BotFather](https://t.me/BotFather))

## 📥 Установка

1. Клонируйте репозиторий:

   ```bash
   git clone <ссылка на ваш репозиторий>
   cd <название папки проекта>
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте необходимые папки:
   ```bash
   mkdir -p logs temp
   ```

## ⚙️ Настройка

1. Создайте файл `.env` в корневой директории проекта со следующим содержимым:

   ```
   BOT_TOKEN=ваш_токен_бота
   MAX_VIDEO_SIZE=20
   TEMP_FOLDER=./temp
   LOG_LEVEL=info
   LOG_FILE=./logs/bot.log
   ADMIN_IDS=ваш_id_телеграм
   ```

2. Замените `ваш_токен_бота` на токен, полученный от @BotFather.
3. Если необходимо, замените `ваш_id_телеграм` на ваш Telegram ID (можно узнать у [@userinfobot](https://t.me/userinfobot)).

## 🚀 Запуск

Для запуска бота в обычном режиме:

```bash
npm start
```

Для запуска в режиме разработки (с автоматической перезагрузкой при изменении файлов):

```bash
npm run dev
```

## 📁 Структура проекта

```
telegram-video-processing-bot/
├── bot.js                  # Основной файл бота
├── scenes/                 # Директория с сценами бота
│   ├── videoProcessingScene.js  # Сцена обработки видео
│   ├── effectsScene.js     # Сцена наложения эффектов
│   └── statisticsScene.js  # Сцена статистики
├── .env                    # Файл с конфигурацией
├── package.json            # Файл с зависимостями и скриптами
├── logs/                   # Директория для логов
└── temp/                   # Директория для временных файлов
```

## 🕹️ Использование бота

1. Найдите своего бота в Telegram по имени, которое вы задали при создании.
2. Отправьте команду `/start` для начала работы.
3. Используйте кнопки меню для взаимодействия с ботом:
   - **🎬 Обработать видео**: позволяет выбрать между конвертацией в кружок или наложением эффектов
   - **📊 Статистика**: показывает статистику использования бота

## 📝 Команды бота

- `/start` - Начать работу с ботом и показать главное меню
- `/cancel` - Отменить текущую операцию и вернуться в главное меню

## 🧩 Особенности реализации

- Бот использует сцены из библиотеки Telegraf для организации диалога с пользователем
- Для имитации обработки видео используются таймеры (в реальном проекте здесь должна быть интеграция с библиотеками обработки видео)
- Статистика хранится в оперативной памяти (в продакшн-версии рекомендуется использовать базу данных)
